# RunMPC

A public catalogue of community-made software that extends Akai MPC and Force standalone hardware.

## Language

**Item**:
One catalogued project: a single piece of community software with its own home (repo, release page or site).
_Avoid_: entry, listing, project, plugin (as the generic word)

**Category**:
The one kind of thing an Item is, such as a mod, an app, a bootloader, a plugin or a dev library. Every Item has exactly one Category.
_Avoid_: type, tag, kind

**Target device**:
A piece of Akai hardware an Item runs on, such as the MPC Sample, MPC Live / X / One or Force. An Item has one or more Target devices.
_Avoid_: platform, hardware, model

**Install method**:
How an Item gets onto a Target device, such as from the SD card, through a modded image, or over SSH.

**Firmware requirement**:
The stock Akai firmware version an Item needs in order to run.
_Avoid_: OS version, compatibility

## Community

**Submission**:
A request from a member of the public to add an Item to the catalogue. It is not an Item until it has been accepted.
_Avoid_: suggestion, entry

**Interest registration**:
A person's request to be told when community accounts open. Making a Submission also counts as an Interest registration.
_Avoid_: signup, waitlist entry, account
